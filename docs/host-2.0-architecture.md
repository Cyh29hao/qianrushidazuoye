# Host 2.0 架构速记

## 页面职责
- `主页`：串口连接、连接并应用、综合数据看板。
- `闹钟与日程管理`：板载单次闹钟 + 多日程提醒。
- `系统设置`：显示与外设、天气/地点、自动昼夜、主题跟随、语音播报。
- `调试与测试`：时间同步、协议调试、自动化测试、OTA 预留。

## 双模式
- `连接串口`：真实和板端同步，日志以 `TX/RX/OK/ERROR` 为主。
- `不使用串口`：进入本地模式，只更新上位机配置与本地模拟状态。
- 未连接真实串口时，所有配置动作也允许本地生效，但日志必须明确写出 `!!! 仅更新上位机本地配置/模拟状态`。

## 关键持久化文件
- `pc_host/config.json`
  - 用户配置
  - 地点槽位
  - 自动昼夜、主题跟随、语音播报、测试开关
- `pc_host/schedules.json`
  - 多日程提醒
- `pc_host/runtime_state.json`
  - 本地模拟的板端状态
  - 只用于无串口模式和断线时的本地回显
- `pc_host/logs/events.jsonl`
  - 最近事件持久化日志

## 板端快捷语义
- `USER1`：切换 `DAY/NIGHT`
- `DISP` 长按：显示与 LED 总开关
- `EXT`：退出/取消当前编辑或临时状态

## 当前数据流
1. UI 动作先更新本地配置或本地模拟状态。
2. 若串口已连接，再下发板端。
3. 板端回包继续反向修正 UI、镜像和数据看板。
