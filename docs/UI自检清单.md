# UI 自检清单

本清单用于 PC 上位机每次 UI 修改后的提交前检查。检查时以真实 Windows 窗口优先，程序化 offscreen 截图只能作为辅助。

## 通用通过标准

- 主窗口使用稳定布局流：左侧主功能区、右侧数字孪生镜像区、底部状态栏互不覆盖。
- 普通窗口约 1600x900 和全屏窗口都可用；空间不足时出现滚动或合理缩放，不允许硬裁切。
- 白天模式和黑夜模式都清楚可读；黑夜模式无白底、浅色块、黑字不可见或灰字过暗。
- 按钮保持统一蓝色主按钮风格，悬停、按下、禁用状态可辨认。
- 下拉框箭头正常，不出现黑色小方块；控制台不刷 `Could not parse stylesheet`。
- checkbox 已勾选状态有明显勾号或填充，未勾选和已勾选清楚区分。
- 小标题和分组标题不压线、不贴边、不骑在边框上。

## 页面检查项

### 主页
- 数据看板保持卡片式布局，不能退回一行行文本堆叠。
- 当前时间、日期星期、城市天气、昼夜模式、下次提醒、系统状态都完整显示。
- 串口状态不放回数据看板，应在串口连接模块附近展示。

### 系统设置
- 用户名、城市、时区、主题跟随、自动昼夜、语音、铃声、滚动速度等控件完整显示。
- label、输入框、下拉框、按钮对齐，不能互相挤压或被右侧镜像遮挡。
- 长说明文本可换行，不产生水平裁切。

### 时间与同步
- 手动编辑写入区和 NTP 自动对时写入区语义清楚，按钮与说明距离紧凑但不重叠。
- 当前城市、时区、当前时间、天气状态每项可读。
- 一键刷新期间界面不假死，日志有立即反馈。

### 闹钟与日程管理
- 日期、时间、执行规则、每周规则、铃声、语音文本、板端标签等输入项完整显示。
- 日程表格列宽合理，不遮挡启用状态和触发时间。
- 双击启停、语音留空不播报等行为说明与 UI 一致。

### 调试与测试
- 自动测试说明文本、预计耗时、状态、逐项输出框完整可读。
- 测试输出长行可换行或滚动，不能被右侧面板或状态栏遮挡。
- 开始测试按钮、自动运行 checkbox、排查提示都清楚可见。

### 数字孪生镜像
- 8 位 7SEG 完整显示，最右侧数字不能被窗口边缘裁掉。
- 8 个 LED 完整显示，编号清楚。
- 两行虚拟按键完整显示，第二行不能只露半截。
- 右侧空间不足时允许右侧区域滚动或压缩内部间距，但不能让日志面板盖住按键。

### 日志区
- 日志面板必须位于数字孪生下方正常布局流中，不能覆盖按键区。
- 最新显示、最新 LED、最近事件、心跳日志、自动滚动 checkbox 都可见。
- 日志文本自动滚动到底部正常，长行可换行或滚动，导出日志内容完整。

### 底部状态栏
- 状态栏不遮挡主内容，且不过度拥挤。
- 连接状态、MODE、地点、时间、延迟、版本、开发者等信息可读。
- 清空、导出、GitHub 按钮保持蓝色，不能把状态栏撑到遮挡上方内容。

## 必跑验证

- 运行 `python -m py_compile pc_host/app.py pc_host/twin_widgets.py pc_host/run_extension_checks.py pc_host/protocol.py pc_host/extension_services.py pc_host/extension_store.py`。
- 运行 `python pc_host/run_extension_checks.py --host-only`。
- 运行 `launch.bat` 或 `pc_host/.venv/Scripts/python.exe pc_host/app.py` 等价启动方式，观察控制台是否无 QSS parse 报错。
- 检查普通窗口和全屏窗口。
- 分别检查 DAY 和 NIGHT 主题。
- 如生成 release，需要重新打包并双击 release exe 做同样检查。
