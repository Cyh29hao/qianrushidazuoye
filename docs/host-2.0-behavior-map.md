# Host 2.0 行为映射速记

## 连接并应用
- 若选中真实串口：连接串口，随后按当前 PC 配置同步板端。
- 若选中 `不使用串口`：进入本地模式，只更新本地状态，不启动串口轮询。

## 一键对时、刷新天气并应用
1. 读取当前地点槽位。
2. 按地点时区生成当前时间。
3. 刷新天气、日出、日落。
4. 更新本地模拟状态。
5. 若已连接串口，再写入板端。

## 切换并应用
- `显示开关 / FORMAT / MODE` 都先改本地状态。
- 若已连接串口，再发对应 `*SET:*` 命令。
- 若未连接，则日志写 `!!!` 本地应用提醒。

## 定位城市
- 主接口：Open-Meteo Geocoding
- 备用接口：Nominatim
- 若都失败：保留旧地点配置，不清空当前天气和时区

## 运行联合测试
- 已连接：复用当前串口
- 未连接但选了真实串口：临时打开并释放
- `不使用串口`：执行 host-only 测试，板端相关项标记 `SKIP（离线模式）`
