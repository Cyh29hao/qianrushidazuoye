# S800 板与 PC 上位机联调测试说明

这份说明按“可以直接照着点、照着看”的方式写，目标是让你自己逐项验收基础功能是否正确。

---

## 1. 测试前准备

### 1.1 PC 端

进入：

```powershell
cd D:\桌面\大二下\大二下 嵌入式系统与接口技术\ARM\大作业524031910102-陈云海\pc_host
```

先确认环境：

```powershell
.\.venv\Scripts\python.exe diagnose_qt_runtime.py
```

期望结果：
- `qwindows_exists=True`
- `qapplication=ok`

然后启动 GUI：

```powershell
.\launch_pc_host.ps1
```

### 1.2 板子端

1. 用 Keil 打开 `mcu/clock.uvprojx`
2. 编译并烧录到 `TM4C1294NCPDT`
3. 连接 USB，让系统能看到一个 `COMx`
4. 再回到 PC 上位机里点击 `刷新`

---

## 2. 总体验收顺序

建议按这个顺序测：

1. 先测“板子离线本地功能”
2. 再测“PC 串口连接”
3. 再测“PC -> 板子命令”
4. 再测“板子 -> PC 事件同步”
5. 最后测“异常情况”

---

## 3. 板子离线本地功能测试

这部分测试时，PC 可以先不连接。

### 3.1 开机动画

观察板子上电后的数码管与 LED。

期望：
- 全亮 -> 全灭
- 学号后 8 位显示并闪烁
- 姓名拼音或缩写显示并闪烁
- 版本号显示约 1 秒
- 然后进入正常显示

### 3.2 时钟显示

正常待机观察数码管。

期望：
- 时间按秒递增
- 不丢秒、不乱跳
- 亮度稳定，无明显串位

### 3.3 日期显示切换

短按 `DISP`。

期望：
- 在 时间 / 日期 / 年份格式 间切换
- 切换后显示内容稳定

### 3.4 滚动与速度

如果当前显示的是长文本或消息：

短按 `SPEED`。

期望：
- 慢速滚动约 `1 s/步`
- 快速滚动约 `500 ms/步`
- 切换后滚动节奏明显变化，但不过快

### 3.5 FORMAT 方向

短按 `FORMAT`。

期望：
- LEFT 模式：正常顺序显示
- RIGHT 模式：显示逆序
- 小数点位置必须跟随正确

### 3.6 编辑状态机

短按 `FUNC` 进入编辑。

期望：
- 编辑顺序：日期 -> 时间 -> 闹钟 -> 退出
- `SHIFT` 切字段
- `ADD` 当前字段加 1
- `SAVE` 保存退出
- 长按 `FUNC` 也能保存退出
- `5 秒` 无操作会自动退出且不保存

### 3.7 闹钟

本地把闹钟设到接近当前时间。

期望：
- 到点开始响铃
- 最长不超过 `10 秒`
- 响铃时按 `FUNC` 可停止
- 闹钟状态有 LED 指示

### 3.8 按键稳定性

快速连续按 `ADD` 或 `DISP`。

期望：
- `1 秒内连续按 3 次以上` 不能明显丢键
- 不应出现一按多触发的严重抖动

## 4. PC 串口连接测试

### 4.1 扫描与连接

1. 在上位机点击 `刷新`
2. 选择正确的 `COM`
3. 点击 `连接`

期望：
- 状态栏显示 `连接: COMx`
- `延迟` 字段开始更新
- 不报串口占用或插件错误

### 4.2 断开

点击 `断开`

期望：
- 状态栏恢复 `未连接`
- 延迟恢复 `--`
- 日志记录断开信息

---

## 5. PC -> 板子命令测试

### 5.1 日期写入

在“时钟与闹钟”中改日期，点 `写入`。

期望：
- 板子日期变化
- 再点 `查询`，应答正确

### 5.2 时间写入

改时间，点 `写入`。

期望：
- 板子时间立即变化
- 再点 `查询`，返回值正确

### 5.3 闹钟写入与关闭

1. 改闹钟时间，点 `启用/写入`
2. 再点 `查询闹钟`
3. 点 `关闭`

期望：
- 写入后能查到新值
- 关闭后返回 `OFF`

### 5.4 同步本机时间

点击 `把本机当前日期时间同步到 S800`

期望：
- 板子时间与 PC 当前时间接近
- 不应发生显示乱跳

### 5.5 显示控制

1. 显示开关选 `OFF`，点 `应用`
2. 再切回 `ON`

期望：
- 板子数码管灭屏/恢复
- PC 镜像同步变化

### 5.6 FORMAT 与 MODE

分别切 `FORMAT` 与 `MODE`。

期望：
- `FORMAT RIGHT` 时 PC 镜像与板子实物一致
- `MODE NIGHT` 时仅保留夜间简化显示

### 5.7 蜂鸣与 LED 覆盖

1. `蜂鸣(ms)` 设为 `500`，点 `触发蜂鸣`
2. `LED 掩码` 输入如 `80` 或 `59`，点发送

期望：
- 蜂鸣器在指定时长内工作
- LED 覆盖动作可见

### 5.8 滚动消息

输入短消息与长消息：

```text
Hello
SJTU_CLOCK_DEMO_2026
```

期望：
- 短消息稳定显示
- 长消息按节奏滚动
- 慢速约 `1 s/步`
- 快速约 `500 ms/步`

## 6. 板子 -> PC 事件同步测试

### 6.1 数字孪生显示同步

观察板子数码管，再看右侧 PC 镜像。

期望：
- 内容一致
- 小数点位置一致
- `FORMAT RIGHT` 时也一致

### 6.2 LED 同步

观察 8 LED 与 PC 圆点。

期望：
- 亮灭同步
- 不应出现明显错位或“上一帧残留”

### 6.3 物理按键事件同步

按板子上的：
- `FUNC`
- `SHIFT`
- `ADD`
- `SAVE`
- `DISP`
- `SPEED`
- `FORMAT`
- `EXT`
- `USER1`
- `USER2`

期望：
- PC 镜像面板能跟随显示状态变化
- 日志能看到关键事件
- `USER1` 可触发 PC 端对时逻辑
- `USER2` 用于天气短显；已有天气缓存时显示天气 token，没有天气时显示 `NO WX`

### 6.4 日志节流

正常待机观察日志。

期望：
- 不再被 `*EVT:DISP / *EVT:LED` 心跳刷屏
- 关键事件仍能看到
- 可以通过“显示心跳日志”打开详细心跳

## 7. 协议调试测试

在“调试与测试”页的“协议测试台”做以下检查：

### 7.1 完整指令模板

从下拉框选择不同类型指令模板，例如 `PING`、`GET TIME`、`SET DATE`、`SET TIME`、`SET DISPLAY`、`SET FORMAT`、`SET MODE`、`SET MSG`、`SET BEEP`、`SET LED`、`SET WEATHER`、`SET KEY` 和错误格式测试，再点击 `发送当前指令`。

期望：
- 命令能成功下发，日志能看到 `TX/RX`
- 板端或 PC 数字孪生出现对应状态变化
- 错误模板能返回清楚的 `ERROR <reason>` 或测试失败提示

### 7.2 缩写当前指令

先选一个完整指令模板，也可以在文本框里手改，再点击 `缩写当前指令`，最后点击 `发送当前指令`。

期望：
- 文本框中的当前指令被改写为协议允许的缩写形式
- 缩写命令仍能被板端识别

### 7.3 随机混合大小写

先选一个完整指令模板，也可以在文本框里手改，再点击 `随机混合大小写`，最后点击 `发送当前指令`。

期望：
- 文本框中的当前指令大小写被随机混合
- 混合大小写命令仍能被识别

### 7.4 手动编辑当前指令

在当前指令文本框里手动输入：

```text
*GET:TIME
*GET:DATE
*GET:ALARM
*SET:FORMAT RIGHT
*SET:DISPLAY OFF
*SET:DISPLAY ON
```

期望：
- 都有明确应答

## 8. 异常情况测试

### 8.1 未连接就发命令

断开串口后点任意按钮。

期望：
- GUI 不崩
- 日志提示未连接

### 8.2 非法 LED 掩码

输入：

```text
ZZ
123
```

期望：
- 板子返回 `ERROR PARAM` 或 `ERROR LEN/RANGE`
- GUI 不崩

### 8.3 非法时间

尝试手动发：

```text
*SET:TIME HOUR 99
```

期望：
- 返回 `ERROR RANGE`

### 8.4 串口断开

连接后拔掉板子 USB。

期望：
- GUI 不崩
- 读写异常被日志记录

---

## 9. 当前基础版通过标准

你可以把下面当成“本轮基础闭环通过”的最小标准：

- 板子本地时间、日期、闹钟、编辑状态机正常
- 慢速滚动约 `1 s/步`，快速滚动约 `500 ms/步`
- PC 能连接串口、发命令、收日志
- 数字孪生与板子显示同步
- `FORMAT RIGHT` 与小数点跟随正确
- 日志不会被心跳刷满到难以调试
- 所有功能操作过程中 GUI 不崩
