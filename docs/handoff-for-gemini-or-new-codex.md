## 3. 这轮最重要的设计原则

### 原则 A：不要重构整个 UI

当前 UI 虽然还有问题，但整体骨架已经基本可用：
- 左侧是折叠菜单
- 右侧上半是数字孪生镜像
- 右侧下半是日志与异常

不要推翻它重做。
只适合继续做：
- 小布局修正
- 颜色和夜间模式补齐
- 控件显隐与交互修正
- 数据内容重排

### 原则 B：无串口模式是正式 feature

不要把“未连接板子”当成错误态。

现在产品逻辑是：
- 若连接真实串口：真机联动
- 若选 `不使用串口`：本地模式，本地配置、本地模拟、本地天气、本地日程、本地测试都继续可用

所以任何“未连接串口就一切失效”的改法都是错的。

### 原则 C：不要新增依赖

当前项目明确不希望再引入新的 Python 包。
优先用：
- 标准库
- 现有项目代码
- 现有 Open-Meteo 方案
- 现有 Qt 组件

## 5. 当前已知重要行为语义

### 板端快捷语义

当前约定是：
- `USER1` -> 切换 `DAY/NIGHT`
- `DISP` 长按 -> 显示与 LED 总开关
- `EXT` -> 退出 / 取消当前编辑或临时状态

如果你改 PC 文案或帮助说明，必须与这个保持一致。

### 无串口模式语义

这套语义已经接入，不要改坏：
- 应用类动作：
  `!!! 仅更新上位机本地配置/模拟状态，未下发板端`
- 查询类动作：
  `!!! 当前显示的是本地保存状态，并非板端实时返回`

不允许出现：
- 一边写 `WARN 未连接串口`
- 一边又写 `INFO 已成功写入 S800`

### 地点与时区

时间同步应使用：
- **当前选中地点所属时区的当前时间**

而不是：
- 本机系统时区时间

## 7. 目前最可能踩坑的地方

### 坑 1：夜间模式漏白

之前已经多次出现：
- `系统设置` 页白底漏网
- 多日程提醒表格白底
- 扩展数据看板列表白底
- 滚动视口仍白

不要只改最外层背景。
要重点看：
- `viewport`
- `QTableWidget`
- `QListWidget`
- `QComboBox` 的下拉视图
- `QScrollArea` 内容区

### 坑 2：按钮颜色被洗灰

之前修主题时，主按钮蓝色风格被冲掉过。
下一轮修改样式时，一定要保护：
- 主按钮蓝色
- hover
- pressed
- disabled

### 坑 3：无串口模式日志措辞

这是最容易改一半的地方。
只要是未连接物理串口，就不能再把任何动作写成“成功写入 S800”。

### 坑 4：城市定位超时

你现在看到过：
- SSL handshake timeout
- geocoding timeout

正确行为不是“清空所有当前状态”，而是：
- 保留旧地点
- 保留旧天气
- 明确写日志说定位失败但已保留旧配置

### 坑 5：不要被页面名字误导

“基础控制”“系统设置”“闹钟与日程管理”“调试与测试”这些页面现在功能已经发生过迁移。
真正要以当前 `app.py` 中的页面组织为准，不要只看旧截图猜逻辑。
