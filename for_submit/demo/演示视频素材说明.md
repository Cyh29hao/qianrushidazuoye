# 演示视频素材说明

本机没有可用的 `ffmpeg` 命令，因此当前没有自动合成示例 mp4。不要用假视频替代实机演示，最终应录制真实 S800 + PC 上位机操作过程。

## 已准备素材

- `demo/screenshots/`：PC 上位机页面截图。
- `submission/演示视频_5分钟脚本初稿.md`：推荐 5 分钟讲解脚本。
- `submission/简介PDF_4-8页初稿大纲.md`：PDF 内容大纲。

## 建议录制镜头

1. 板端 RESET 开机：全亮、学号、拼音、`V2.2`。
2. 板端 DISP/FORMAT/SPEED/FUNC 本地操作。
3. PC 打开 v2.2 exe，连接 COM5，自动 NTP。
4. 数字孪生跟随板端显示。
5. USER2 天气短显。
6. 新建当前时间 +1 分钟日程，等待触发并听到铃声。
7. 快速联合测试或全面联合测试片段。
8. 总结 GitHub 版本管理、自动测试、高并发防卡死和用户友好 UI。
