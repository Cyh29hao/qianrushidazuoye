# 提交前检查清单

## 1. MCU

- [ ] Keil5 打开 `mcu/clock.uvprojx`。
- [ ] Rebuild all target，无编译错误。
- [ ] 烧录 S800/TM4C1294。
- [ ] RESET 后看到 `88888888`、学号、拼音、`V2.2`。
- [ ] DISP 可循环时间、日期、星期、年份。
- [ ] 闹钟和 PC 日程提醒都能听到蜂鸣。

## 2. PC

- [ ] 双击 `release/SmartClockHost-v2.2/SmartClockHost.exe` 或解压 `SmartClockHost-v2.2.zip` 后启动。
- [ ] 窗口标题/底部状态栏显示 v2.2。
- [ ] 底部为 `智能联网时钟系统 · 串口孪生 · NTP天气 ...` 风格，无遮挡。
- [ ] 图标不是默认占位图。
- [ ] 连接 COM5 后自动对时，日志可读。
- [ ] 数字孪生能同步板端显示帧和 LED。

## 3. 自动测试

- [ ] 快速联合测试通过。
- [ ] 全面联合测试通过，失败时能停止并给出提示。
- [ ] 测试后恢复原先 DAY/NIGHT、FORMAT、DISPLAY 和自动昼夜设置。

## 4. 演示材料

- [ ] 简介 PDF 4-8 页完成。
- [ ] 演示视频不超过 5 分钟。
- [ ] 视频中包含：板端开机、本地按键、串口连接、数字孪生、NTP/天气、日程提醒、自动测试。
- [ ] 最终 zip 命名符合老师要求。

## 5. 自主答辩重点

- [ ] 能讲清楚 1 ms SysTick、非阻塞主循环、I2C 扫描、按键防抖。
- [ ] 能讲清楚串口协议 `SET/GET/EVT/ERROR`。
- [ ] 能讲清楚数字孪生的数据源优先级。
- [ ] 能讲清楚 NTP/天气异步与 timeout。
- [ ] 能讲清楚高并发防卡死与串口 watchdog。
- [ ] 能讲清楚 GitHub 版本管理和 v2.2 release。
